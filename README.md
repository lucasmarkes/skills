# skills

Skills for coding agents, each one a command away.

## Install

```bash
npx skills add lucasmarkes/skills
```

Add `--skill specimen` to install just that one.

## Skills

| Skill | What it does |
|---|---|
| `specimen` | A glossy 3D icon on a soft tile, lit like a display piece and looping, in dark and light, shipped as video or live with nothing to install. |
