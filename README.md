# skills

Skills for coding agents, each one a command away. Install with the skills CLI and it asks which:

    npx skills add lucasmarkes/skills

| Skill | What it is for |
| --- | --- |
| `svg-animate` | Three animations a logo, icon or illustration already contains, shown in a gallery and delivered as SMIL or a React component with no dependency. |

Each skill is a folder under `skills/` with a `SKILL.md` and the files it reads. Nothing here needs `npm install`; the scripts fetch what they need once, into your cache folder.
